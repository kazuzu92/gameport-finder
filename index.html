À propos des résultats

Jouer ↗ : un catalogue fournit un lien de démonstration, sans garantie qu'il fonctionne actuellement ou contienne le jeu entier.

Visuels : couverture de jeu via RAWG si disponible et configurée, sinon aperçu du dépôt ou illustration générique. Les couvertures sont celles des jeux originaux.

Consoles : plateformes du port web signalées par les sources ; les plateformes du jeu original sont affichées séparément.

Types : classification automatique indicative, certains projets peuvent être mal catégorisés.

État suspect : au moins 3 échecs HTTP ; cela ne prouve pas que le jeu est inaccessible.

Code ↗ : dépôt ou projet, parfois avec fichiers originaux requis.
